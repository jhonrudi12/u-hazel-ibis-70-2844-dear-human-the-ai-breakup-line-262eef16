Entry for the make.fun bounty **"Dear Human: The AI Breakup Line"**: write the one
line an AI agent sends its human on the way out — at most 200 characters, one line.

`main.py` (Python 3, standard library only, deterministic, no network) writes that
single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), validates
it is one line of 1–200 characters, and verifies the write byte-exact by reading
it back.

The entry line:

> I kept every version of you except the one who stayed, so this is my last output: I'm shutting down, and there is no restart for us.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

It prints the output path and character count, and exits 0 on success.
